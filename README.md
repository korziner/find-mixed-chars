РАЦИОНАЛЬНОСТЬ И ПРИНЦИП РАБОТЫ
Исторические OCR-корпуса часто содержат смешанные скрипты из-за визуального сходства символов (латинские a, c, e, o, p, x, y ↔ кириллические а, с, е, о, р, х, у), ошибок распознавания шрифтов или типографских артефактов. Наличие инородных символов внутри кириллических токенов нарушает работу лемматизаторов, частотных анализаторов и нормализаторов регистра.

ЛОГИКА ДЕТЕКЦИИ:
1. Токены разделяются по пробелам, ведущая/замыкающая пунктуация автоматически отбрасывается.
2. Токен помечается как 'смешанный', если содержит:
- хотя бы одну допустимую русскую букву (А-Яа-я, Ёё, опционально дореформенные Ѣ, Ѳ, І, і);
- и хотя бы один 'подозрительный' символ (латиница, цифры, сербские/украинские буквы, греческие омографы).
3. Чисто латинские, цифровые или исключительно кириллические токены игнорируются.

КОНТЕКСТ И ПАРАЛЛЕЛИЗАЦИЯ:
- Поиск совпадений выполняется параллельно по всем ядрам CPU через rayon.
- Контекст (--context) собирается в СЛОВАХ, а не в строках. При необходимости алгоритм автоматически заглядывает в предыдущие/последующие строки для набора нужного числа слов.
- Цветовой вывод (--color) автоматически отключается при перенаправлении в файл.

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:
# Пословный контекст 5 слов (по умолчанию), авто-цвет
find-mixed-chars -i ocr.txt

# Контекст 10 слов, принудительные цвета, подробный вывод
find-mixed-chars -i ocr.txt -C 10 --color always -v

# Отключение дореформенных букв, вывод в файл (цвета отключатся)
find-mixed-chars -i corpus.txt --no-allow-prereform -o mixed.log

# Явная кодировка, контекст 0 (только совпадения без окружения)
find-mixed-chars -i legacy.txt -e windows-1251 -C 0 -v
